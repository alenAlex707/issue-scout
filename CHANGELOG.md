# Changelog

All notable changes to Issue Scout are documented here.

## [0.1.0] - 2026-07-13

### Added

- GitHub issue search with language, label, repository, assignment, and raw-query filters.
- Transparent candidate scoring with a human-readable breakdown.
- Optional detection of linked open pull requests through issue timelines.
- Table, JSON, and CSV output formats.
- Automated tests across Python 3.10 through 3.13.
